配置分区
左边选一块，右边只显示它。
普通用户从首页 / 进来，看不到这里的任何内容。

默认规则

这是默认规则：房间没有自定义规则时，模型每轮收到的就是这一份。
房主在首页「房间设置 → 本房间规则 / 角色」里改的是他自己房间那一份 （可逐条增删 —— 包括删掉这里的默认条目，删的是他那间、不影响这里）。
所以这里改的是默认值，管不到已经自定义过的房间。改完点「保存规则」 立刻生效，不用重启；首页左栏的「规则」模块同步更新。

默认角色

这是默认角色库：房主给房间参与者「设角色」时，选的就是这里的条目 （按「分组」折叠展示）；房主删不掉这里的条目 —— 他只能在自己房间里另外新增。
⚠️ 删掉一个还有人在用的角色，那些参与者会变成「未设置角色」（不会崩，但设定丢了）。

模型库

这里是全站唯一的模型库，各房间只是「引用」其中的条目。
每张卡片都要写对「模型 ID」和 base_url —— 探活失败九成是这两处，别先怀疑代码。
⚠️ 删掉一条 = 所有引用它的房间参与者名单里也会被摘掉（会二次确认）。

厂商 / API Key

Key 只存在本机 config.json，不会上传任何地方；页面里也只显示前 6 位 + 后 4 位的提示。
增加厂商预设 / 改 base_url 要手工改 config.json，改完点右上「重载」。

用户库（昵称账号）

昵称即账号：不需要密码，同一个昵称在任何设备上都是同一个人。
⚠️ 「移除」= 直接删除这个用户： 他从所有聊天室的成员表里消失、进行中的连接立刻断开。
昵称随即变成没人占用 —— 谁（包括他本人）再填这个昵称进来，就是重新登记，
他的历史发言会保留（只清人、不清话）。

房间库

这里是全部房间，包括别人在首页建的（普通用户只能看到自己的房间号与自己的回收站）。
公开＝不用房间号谁都能进；人人可管理＝默认讨论室（没有房主，也不给删）。
⚠️ 删除房间 = 放进回收站（不是硬删）：房间配置 + 全部历史消息一起进去， 之后还能在管理员自己的回收站里还原。删除操作会记成「管理员删的」， 所以不会出现在普通用户的回收站里。
